## 👨‍💻 Profile Executive Summary

I am a **Computer Science & Engineering student specializing in Data Science**. My work focuses on bridging raw analytical pipelines with practical user applications—turning machine learning algorithms into full-stack AI products.

### 🎯 Core Capabilities
* **AI & Agentic Systems:** LLM Integration (Gemini API), Prompt Engineering, Automated Workflows.
* **Data Engineering & ML:** Data Cleaning, Exploratory Data Analysis, Predictive Modeling, Scikit-learn.
* **Full-Stack Engineering:** Microservice Architecture (FastAPI), Modern Frontend (React + Vite), Relational Storage (PostgreSQL).
